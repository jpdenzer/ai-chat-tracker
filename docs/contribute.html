Report an incident

One report per incident. When you submit, this page opens a prefilled GitHub issue. You review it there and click Create. Maintainers review every submission before it appears in the log.

Privacy warning

Do not submit personal data, confidential or proprietary material, credentials, or other people's private information. Redact names, emails, IDs, file paths, internal URLs, and anything you wouldn't post publicly. Issues on GitHub are public as soon as you create them.

Chat links are optional. Links to private chats won't work for anyone else, and a shared link can expose the whole conversation, not just the part you quote.
