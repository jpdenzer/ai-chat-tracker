AI Chat Anomaly Log

A public, community-contributed log of odd or inconsistent behavior by AI assistants: instruction drift, fabrication, odd refusals, self-contradiction, caving under pushback, and identity or tone oddities. One row per incident.

Privacy: Do not submit personal data, confidential or proprietary material, credentials, or other people's private information. Redact before submitting. Every submission is public.

Entries are reports of observed behavior submitted by individuals. They are not verified claims about any vendor's product, and a single report says nothing about how often a behavior occurs. Maintainers review each submission for format, privacy, and tone before it appears in the log.

Contribute

How to contribute

  1. Web form (easiest): use the Contribute page. It checks your entry, then opens a prefilled GitHub issue for you to submit. You need a GitHub account.
  2. Issue form: open a new “Report an incident” issue directly on GitHub.
  3. Pull request: add one JSON file to data/entries/. See CONTRIBUTING.md. The Contribute page can download a correctly formatted file for you.

Request removal

If an entry contains your personal information or should not be public, open a removal request with the entry id. Don't repeat the sensitive information in the request. If the issue itself would expose something sensitive, use the private reporting route in SECURITY.md. Maintainers remove entries promptly.
